# List of OpenIFS Experiments
 
This page provides an overview of the available OpenIFS experiments referred to in the documentation.

All experiments are initialised on 25 September 2016 00 UTC and simulate the extratropical transition of Tropical Storm Karl.


## Overview table

The table below lists the available **experiment IDs** and their corresponding **model cycle**.
 
| Model Cycle | Experiment ID |   Model Grid     | Levels |
|-------------|---------------|------------------|--------|
|   48r1      |    ab7z       |   N80 / T159     |   60   |
|   48r1      |    ab2a       |   N128 / T255    |   91   |

For more information on the Gaussian model grids, please see the following page on the ECMWF Confluence Wiki:  
https://confluence.ecmwf.int/spaces/OIFS/pages/431064380/3+Horizontal+Resolution+and+Configurations


## Downloading experiment data packs

All OpenIFS experiments listed in the table above can be downloaded from the OpenIFS download site here:  
https://openifs.ecmwf.int/data/experiments/2016-09_Karl/

The experiment data packs are organised into subdirectories named according to the **model cycle**. Each data pack is named after the corresponding **experiment ID** and is provided as a `.tar.gz` archive.

**Example:**  For model cycle **48r1**, the N80/T159 experiment has the experiment ID `ab7z`. The corresponding data pack can be downloaded from: https://openifs.ecmwf.int/data/experiments/2016-09_Karl/48r1/ab7z.tar.gz
